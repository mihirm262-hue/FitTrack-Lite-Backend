# FitTrack Lite — Backend

## About the Project
FitTrack Lite is a full-stack fitness and workout progress tracking platform. This repository contains the backend component of the project.

## Technologies Used
- Java
- Spring Boot
- Maven
- Spring Data JPA
- Spring Security
- MySQL
- REST APIs

## Requirements
- Java JDK
- MySQL Server
- Maven

## How to Run
1. Clone or download this repository.
2. Configure your MySQL database credentials.
3. Open a terminal in the backend project folder.
4. Run the following command:

   `mvn spring-boot:run`

## Project Structure
- `src/` — Backend source code
- `pom.xml` — Maven dependencies and build configuration
- `Dockerfile` — Container configuration
